# 模型怎麼跑的（給隊友的白話說明）

> 這份是讓非 ML 背景的隊友理解「系統裡的 AI/模型到底是什麼、怎麼跑、花不花錢」。

---

## 一句話版

**我們自己訓練一個預測用的數學公式，存在自己的電腦上，之後要算的時候直接跑，不花錢、不需要網路。它不是 ChatGPT 那種生成式 AI。**

---

## 分兩個階段

### 階段 1：訓練（做一次，建立「方程式」）

```
歷史資料（1~5月，1583站，每30分一筆）
    ↓ 餵進 LightGBM
自動學出一個「方程式」
    ↓
存成一個檔案（幾 MB，放在 prediction/artifacts/）
```

- 這個階段就是 B 工程師的主要工作：選哪些因子（天氣、地形、時段...）放進去、調權重、讓算出來的值接近真實值
- 跑在你自己的電腦上，不呼叫任何外部 API，不花錢
- 訓練一次幾分鐘（用 6 個月資料約 1~2 分鐘）
- 每日微調（② AI 最適化）也是在自己的機器上跑

### 階段 2：推論（上線後每次要判斷時，用「方程式」算）

```
現在這站有 12 台車 + 現在是平日早上 8 點 + 下雨
    ↓ 餵進已存好的「方程式」
算出：預計 30 分鐘後剩 4 台（區間 1~8 台）
    ↓
規則引擎拿這個數字去判斷要不要調度（純 if-else，不是 AI）
```

- **推論跑在自己的機器上，完全免費**
- 1583 站全部算完 < 0.1 秒（毫秒級，比你按下按鈕還快）
- 不需要網路（模型檔在本地）
- 你想跑幾萬次都不花錢

## 跟 ChatGPT 的差別

| | ChatGPT / Claude | 我們用的 LightGBM |
|---|---|---|
| 在哪跑 | 別人的雲端伺服器 | **你自己的電腦** |
| 每次要錢嗎 | 要（按字數計費） | **不要，免費** |
| 速度 | 幾秒 | **幾毫秒** |
| 做什麼 | 聊天、寫文 | **數字預測（輸入 → 算 → 輸出數字）** |
| 像什麼 | 像找一個很聰明的人幫你回答 | **像一個很複雜的 Excel 公式** |

---

## 系統裡什麼地方用到模型、什麼不用

| 環節 | 用模型嗎 | 說明 |
|------|:---:|------|
| 預測未來存量 | ✅ | LightGBM 跑一下，本地免費 |
| 每日參數微調 | ✅ | 也是本地跑，免費 |
| 緊急度計算 | ❌ | 加權公式（像 Excel） |
| 規則引擎（要不要調度） | ❌ | if-else 判斷 |
| 排序派車 | ❌ | 演算法排序 |
| 警示/覆寫/任務管理 | ❌ | 全是規則 |
