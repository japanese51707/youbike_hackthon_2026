# ADR-001：單一模型 + 分層參數（非 1583 個模型）

狀態：已定案（2026-08-31）

## 決策

全市用**一個統一預測模型** + **每站一組條件參數**，而不是為 1583 個站各建一個模型。

## 脈絡

新北市有 1583 個站，每站空滿模式不同。直覺會想「每站一個模型」，但這樣：不可維護、無法統一升級、新站沒資料無法建模。

## 替代方案

- **A：1583 個獨立模型** — 每站自己的模型。否決：不可維護、新站冷啟動無解。
- **B（採用）：單一模型 + 分層參數** — 一個模型吃「站點條件參數 + 時間 + 外部因子」，站點差異靠參數表達。

## 理由

- 改模型 = 全市一起升級（一處改，全站受惠）
- 新增站別不需訓練新模型，套當前模型 + 鄰近站參數即可冷啟動
- 參數分三層（①規則化基礎 ②AI每日最適化 ③即時覆寫），可解釋、可回溯

## 影響

- 模型：B 訓練一個 LightGBM，特徵含站點條件參數
- 參數管理：需要 params/ 三層 + 版本控制（design §8）
- 站點動態增減：只重算受影響鄰近站（FR-13）
