# ADR-015：預測目標變數定義與截斷（censored）樣本處理

## 背景與問題

進訓練前審查（review_model_pretraining_v1.md F-03）指出本專案最大的統計陷阱：

**目標變數在空站／滿站被截斷（censored）。** 站空了之後仍有人想借車，但觀測到的 Δ（可借車數變化）是 0——因為沒車可借，真實需求被物理邊界切掉。滿站對稱（沒位可還）。

後果：模型從資料學到「空站之後不會再變少」，於是**系統性低估空站的嚴重程度**。而空站正是整個系統存在的理由——這個陷阱正好落在最關鍵的區域。

另一個相關問題（審查 §5 附註）：特徵含「可借車數(t)」、目標是「Δ(t→t+1)」，在邊界上特徵**機械地決定**目標的取值範圍（可借=0 時 Δ 不可能為負）。模型會學到這個恆等式，在邊界區「表現異常好」——那不是預測能力，是評估假象。

目前狀態（現況查證）：真實訓練 pipeline 尚未建立，故此陷阱**尚未實際發生**；本 ADR 目的是在建 pipeline 前把目標定義與截斷處理訂死。

## 決策（proposed，待 owner 核准）

1. **目標變數定義**：預測「下一時段淨流入/流出量（Δ 可借車數）」的方向不變（對齊 ADR-002/004，規則引擎吃區間下界/上界）。但明確標註：Δ 在觸底/觸頂樣本上是「被壓抑的觀測值」，非真實需求。

2. **截斷樣本標記與處理**（至少做 1、2）：
   - **標記（精確條件，owner 修正）**：截斷樣本 = **「Δ=0（或 Δ 方向與邊界一致）」AND「同時處於空站(可借=0)或滿站(可還=0)」**。
     只有這種情況的 Δ=0 才是「被物理邊界壓抑的假需求」（想借但沒車 / 想還但沒位）。
     **正常水位下的 Δ=0 不是截斷，是真實的「這時段沒人借」訊號，必須保留**（否則模型學不到「何時不需調度」）。
   - **訓練**：被標記為截斷的樣本才**排除或降權**（權重可 config）；正常站的 Δ=0 照常當有效資料訓練。
   - **評估分區間**：評估時分「健康水位 / 接近空 / 已空」三段各報 MAE 與區間覆蓋率，不只報整體平均（整體會被健康區稀釋，掩蓋危險區失準）。
   - **進階（選配，owner 核准列為選配）**：用同群站在同時段「未觸底時」的流量，插補被壓抑的真實需求。
     即「猜測被截斷掉的真實需求量」——例如空站觀測 Δ=0，但同群站同時段未空時流出 15 台，反推此站真實需求約 15 台流出。
     此為簡報加分項（「還原官方快照低估的空站真實缺口」），**成本較高，列為選配，非必要**。

3. **不改核心約束**：AI 只估計、規則引擎吃區間下界（ADR-004）不變。本 ADR 只處理「訓練目標的正確性與評估的誠實性」。

## 理由與判準

- **正確性**：截斷樣本的目標值是假的，用它訓練會系統性低估空站嚴重度
- **評估誠實**：分區間評估才看得出模型在「實際使用區域（危險區）」的真實表現，避免整體平均的假象
- **簡報價值**：分區間報告 + 需求還原是很有份量的一段（誠實面對資料限制）

## 考慮過的替代方案

### 不處理截斷，直接用原始 Δ
- 未採用：系統性低估空站，且評估假象會讓 MAE 虛低

### 改預測「可借車數絕對值」而非 Δ
- 保留評估：兩者在邊界都有截斷問題；Δ 對規則引擎更直接（觸發看到達存量）。此替代待 F-06 目標尺度實驗一併評估，非本 ADR 定案範圍

## 影響與後果

### 正面
- 模型不再學假的邊界恆等式，空站區預測更誠實
- 分區間評估揭露真實表現，避免 Demo 當天才發現危險區失準

### 負面與代價
- 排除/降權觸底樣本會減少訓練資料量（但那些樣本本來就是假的）
- 需求插補（進階項）成本較高，列為選配

### 尚未解決
- 截斷樣本「排除」vs「降權」哪個好，待 pipeline 建立後以實驗定（判定條件已明確：Δ=0 且空/滿站）
- 降權權重、分區間的界線（接近空 = 可借 ≤ 幾台）待校準
- 需求插補（選配）是否實作，視時間與簡報需求決定

## 介面與相容性

- 影響訓練資料處理與評估報告，**不改** core/interfaces.py 的 PredictionInterval
- 特徵組裝 pipeline（待建）需實作截斷標記與分區間評估

## 資安與隱私

- 無（純訓練資料處理）

## 回復或取代方式

- 截斷處理可獨立開關（config）；設計變更以新 ADR supersede

## 驗證方式

- **待特徵組裝 pipeline 建立後**：比較「處理截斷前後」的分區間 MAE，尤其「已空」區間的改善
- 確認觸底樣本被正確標記（可借=0 或 可還=0）
- 分區間覆蓋率報告（健康/接近空/已空）
