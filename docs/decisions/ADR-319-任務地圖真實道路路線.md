# ADR-319：任務地圖以真實道路路線呈現（非點對點直線）

## 背景與問題

派工單／組單草稿的地圖原本以「起點→各站」的直線串接呈現路線。對司機而言，直線無法反映實際
道路，看不出怎麼走。owner 要求路線像 Google Maps 一樣沿著實際道路顯示。

限制：金鑰與外部服務呼叫應留在後端（前端不直接打第三方路由服務，避免 CORS 不保證與金鑰外流）；
路由服務不可用時仍要畫得出路線（demo 不能開天窗）。

## 決策

**由後端提供道路路線端點，前端沿實際道路折線畫路線**：

- 後端 `POST /api/v1/routing/road`（`backend/api/routing.py` + `core/road_routing.py`）：
  收 `coordinates`（`[[lng,lat],...]` 起點與各站序列），呼叫路由服務（OSRM／Valhalla）取實走
  道路幾何，回 `{mode, geometry}`。服務不可用時**降級為直線幾何**並回 `mode="straight"`（呼叫端
  照實顯示，不假裝實走）；結果以約 30 分鐘快取，避免重複外呼。
- 前端 `routingApi.getRoadRoute(coordinates)` 呼叫該端點；`planLayers.createPlanRouteLayers`
  支援 `geometry` 參數：有實走幾何就沿道路畫，無則退回起點→各站直線串接。
- 司機端 `BackendDriverPage` 與後台組單預覽 `DashboardPage`／`StationMap` 皆接：路線／站序決定後
  以座標序列打 `/routing/road` 取 geometry，僅在 `mode="road"` 且對應到目前這條路線時採用（站序
  改變時不沿用舊線）。

前端**不直接呼叫外部路由服務**。

## 理由與判準

- **架構一致 / 資安**：外部服務呼叫與任何金鑰留後端，前端只打自家端點，避免 CORS 不確定性與
  金鑰外流（與既有「金鑰留後端」原則一致）。
- **可用性優先**：後端保證「一定回得了東西」——路由服務掛掉時降級直線且明確標 `mode`，demo 不
  開天窗；前端照實呈現降級狀態。
- **效能**：後端快取路由結果（約 30 分），同一路線重複請求不重打外部服務。
- **低破壞**：`createPlanRouteLayers` 以可選 `geometry` 參數擴充，未給時行為與原直線一致。

## 考慮過的替代方案

### 方案 A：後端代理路由 + 直線降級（採用）

- 優點：金鑰／CORS 留後端、可快取、可降級、前端改動小。
- 缺點：多一個後端端點與外部相依。
- 未採用原因：無——這是採用方案。

### 方案 B：前端直接打 OSRM 公開服務

- 優點：後端不必改。
- 缺點：CORS 不保證、外部服務穩定性不可控、若換成需金鑰的服務會外流金鑰、違反金鑰留後端原則。
- 未採用原因：資安與架構一致性考量，且穩定性不可控。

## 影響與後果

### 正面

- 司機與後台看到的路線沿實際道路，符合 Google Maps 式體驗。
- 路由服務不可用時仍畫得出（直線降級）且誠實標示。

### 負面與代價

- 新增後端端點與對外部路由服務的相依（已以快取 + 降級緩解）。

### 尚未解決

- 未做逐段轉彎指引（turn-by-turn 文字）；本 ADR 僅路線幾何呈現。

## 介面與相容性

- **API**：新增 `POST /api/v1/routing/road`，body `{coordinates:[[lng,lat],...]}`，回 `{mode, geometry}`。
- **前端**：`routingApi.getRoadRoute`；`createPlanRouteLayers({start, route, geometry})` 新增
  可選 `geometry`；`StationMap` 轉傳 `draftRoute.geometry`。未給 geometry 時退回直線（相容）。
- **設定**：路由服務位址／降級行為於 `core/road_routing.py` 內處理（本 ADR 不細列 config 欄位）。

## 資安與隱私

- 外部路由服務呼叫留在後端；前端不直接對外。若路由服務需金鑰，金鑰留後端環境變數，不進前端／版控。
- 只傳站點座標序列（非個資）給路由服務。

## 回復或取代方式

- 前端不傳 `geometry` 即回到直線串接；後端端點可停用。未來加 turn-by-turn 以新 ADR 擴充。

## 驗證方式

- 前端 `npm run build` 通過；司機端與後台組單預覽地圖在有 geometry 時沿道路畫、無時退直線。
- 後端路由端點在服務不可用時回 `mode="straight"` 幾何（降級路徑）。
