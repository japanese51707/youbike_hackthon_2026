# 資料存放說明

> 資料不進 Git（太大，且應有單一真實來源）。全部放 AWS S3。

## S3 位置

Bucket：`s3://youbike-hackathon-2026/`（region: ap-northeast-1）

| Prefix | 內容 | 說明 |
|--------|------|------|
| `raw_csv/` | **主辦提供的原始 12 個 CSV** | 找主辦給的原始資料，到這裡 |
| `youbike_data/` | 整合後的分區 Parquet（year_month=2026-01 ~ 06） | 模型/分析用，已清洗合併 |
| `athena-results/` | Athena 查詢結果 | 自動產生 |

## 資料流

```
主辦原始 CSV ──(merge_csv_to_parquet.py)──▶ 整合 Parquet
   存 raw_csv/                                存 youbike_data/
                                                  │
                                          Athena 查詢 / 模型訓練
```

## 隊友怎麼取得資料

1. 設定 AWS credentials（見 `.env.example`，跟 A 拿臨時憑證）
2. 從 S3 拉資料到本地：
   ```bash
   # 原始 CSV（若要重新整合）
   aws s3 sync s3://youbike-hackathon-2026/raw_csv/ ./data/raw_csv/
   # 整合後 Parquet（直接用於分析/模型）
   aws s3 sync s3://youbike-hackathon-2026/youbike_data/ ./data/youbike_parquet/
   ```
3. 本地 `output/`、`youbike資料集/`、`*.parquet`、`*.csv` 都在 .gitignore，不會進 Git

## 資料規格

- 原始：12 個 CSV，1~6 月，混合編碼（1/2/6月 UTF-8，3~5月 Big5）
- 整合後：13,324,945 筆，1,583 站，29 行政區，每 30 分鐘快照
- 欄位：日期、城市、行政區、場站名稱、總車柱數、可借車數、可還位數、經度、緯度
- 詳見 `.kiro/specs/youbike-dispatch-system/requirements.md §5`

## 關閉/省錢

- S3 儲存費極低（約 NT$ 幾元/月）
- 要完全關閉：`python teardown_aws.py --bucket youbike-hackathon-2026`（會刪除所有資料，謹慎）
